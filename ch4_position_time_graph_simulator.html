The slope of a position–time graph represents velocity.

Steeper slope → greater velocity.
Horizontal line → object is at rest.
Explore five graph patterns:
At Rest
Position does not change. Graph is horizontal.
Uniform Motion
Straight rising line with constant slope.
Faster Motion
Steeper straight line means higher velocity.
Return Journey
Position rises and then falls back.
Acceleration
Curved graph because velocity changes.
