Key physics relation
N = mg; fs ≤ μsN; fk = μkN

What to Learn

For a level horizontal surface with no other vertical forces, N = mg. Static friction adjusts up to its maximum; kinetic friction opposes sliding.

Student activity: Change one variable, record the results and explain the effect using the formula. Compare a zero-force case with a nonzero-force case.
